- Resource claims (`claude_hooks/resources/`, reference `docs/resources.md`) replace before/after mail for shared machines: claim with `claude-hooks-res acquire|wait|run` or the `resource-*` MCP tools, release when done. Waiting is a background `claude-hooks-res wait …`, whose exit is the notification.
- The policy is pure and lives only in `model.py`: `items_conflict()` (shared / exclusive / quiet over `/`-separated names, quiet = the whole root host), `blocker()` (conflicts + capacity), `decide()` (strict FIFO: a claim waits behind every earlier conflicting waiter). A multi-item claim is granted all or nothing. Two claims of one session conflict (opencoti bug-4004). Never decide grants anywhere else.
- Every write goes through `ResourceStore._run()`: one transaction under `pg_advisory_xact_lock(ADVISORY_KEY)` (SQLite: `BEGIN IMMEDIATE`) that settles first (drops `expired` / `holder_gone` / `lease_lapsed` claims, grants by `decide()`) and sends `pg_notify(CHANNEL)` on any change. A waiter opens its `LISTEN` before its first check. Hot paths (PreToolUse note, quiet check) read `snapshot()`, which never takes the lock and never writes.
- Liveness: a claim follows `pid` + `pid_started` on its own host (the session's Claude Code process via `client_process()`, or the `run` wrapper's own pid); other hosts trust `renewed_at + lease_s` (default 1800 s). Renewals: hooks (`touch()`, ≤ 1/min), waiters, `run`, the daemon's `ResourceMaintenanceThread`. SessionEnd releases the session's claims except `run` jobs (`_is_claude_pid`).
- The store owns its connection (not the provider's): pgvector DSN when enabled, else sqlite_vec's file, else `~/.claude/claude-hooks-resources.db`; `CLAUDE_HOOKS_RESOURCES_DB` overrides and `tests/conftest.py` sets it per test — never let a test reach the shared table. Live Postgres tests run in a throw-away schema only with `CLAUDE_HOOKS_RESOURCES_TEST_DSN`.
- Hooks (`claude_hooks/resources/hook.py`) soft-fail: session block, renew, session-end release, PreToolUse note (advisory, once per claim per session, never a denial; the local host counts only for quiet or host-level exclusive claims). Marker route: part `resources` in `claude_hooks/hook_parts.py`. Background work that would disturb a measurement checks `api.quiet_holder()` (the Stop hook's claudemem reindex does).
- A tool added to one memory server goes on the other (`_resources()` in both `pgvector_mcp/server.py` and `sqlite_vec_mcp/server.py`). `scripts/verify_deploy.py` `check_resources` reads the store. Tests: `tests/test_resources.py`, `tests/test_resources_hooks.py`.
