## Description
Adopt beads' (gastownhall/beads, MIT) graph model into claude-hooks tasks for long-horizon, cross-project work. Plan: docs/PLAN-task-graph.md.

Phase 0 (prerequisite): one canonical root per project. Today the index identity is the config.toml project name, reconcile() registers whatever root it runs in and deletes rows for files that root lacks, and id allocation reads only the local folder. A session in an opencoti release worktree (20 linked worktrees share project "opencoti") would rewrite 127 rows with older versions, delete 220 live rows from the index and re-point the root; a task created there could reuse a number main already handed out. Files are never touched, so a later main reconcile heals the index — but cross-project lookups need it right. Measured 2026-11-19: index clean (all 347 op rows from the main checkout), no worktree holds an id main lacks.

Then: cross-project depends via the host index + cycle check; typed links (parent, discovered-from, related, supersedes/duplicates, caused-by); unblock reporting + doorbell to the owning session; gates (mail, human, gh:pr, gh:run, commit, timer); task-graph / task-blocked views; atomic claim; defer.
