## Description
From ch-10 (2026-10-24 run 3, 32,768-cell engine): each placed call asks its prompt past the layer plus its full output allowance (min(0.75 × window, 96k)), so two researcher lanes beside a ~17.5k layer cannot both be admitted and one fails after the engine's 2-min queue. At 589,824 cells this no longer bites, but it does on any small engine. Safeguard: under pooled/assured, cap a lane's output allowance at (pool cells − layer chain) ÷ concurrent lanes (from /props kv_pool_cells and the run's live lane count), never below the budget floor, stated in the role's # Output Budget so the prefix cache holds.

- [ ] no change when the pool is large enough (byte-identical payload)
