## Description
Compaction bench v2/v3: reduced 0/8, then 0/12 in every arm once the grep leak was closed. Root cause from the traces: budget.plan_cut keeps the head (system + question) verbatim, so the writer is never shown the task. It took one from the prompt's example ("fixing the collision"), dropped the decisecond fact and narrated edits that were never made. The fork shows its pinned first prompt to the summarizer (agentic-compaction.ts:579-605). Also fixed: the writer's input is now the window-sized budget (was 0.5×target) and the half-critics get the full summary cap. The first attempt's fork-divergent mechanisms were reverted.
