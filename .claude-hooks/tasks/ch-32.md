## Description
claudemem's global config on BOTH hosts (~/.claudemem/config.json on solidpc, C:\Users\manni\.claudemem\config.json on pandorum) sets embeddingProvider=ollama, ollamaEndpoint=http://192.168.178.2:11433 (nginx → xollama on the solidpc 3090), model snowflake-arctic-embed2. So every claudemem index on either host loads the GPU; a session running `claudemem index` by hand never checks for a measurement (the hooks' reindex does, via api.perf_holder). Seen 2026-11-27 07:35:14–47 CET: a RomulusAI index made 710 embed calls inside xollama's quiet window. Owner decision (2026-11-27): move claudemem to the CPU embedder, but later — the model change is a new vector space, so every claudemem index must be re-created, and the owner does not want that now. Indexes on solidpc today (7, ~7.7 GB): RomulusAI 4.7G, claude-hooks 2.5G, caliber-eval/glm-5-1-cloud 310M, anycubic 130M, lightseek 52M, YouthGuardAI 23M, acproxycam 1.9M; pandorum's not yet listed.
