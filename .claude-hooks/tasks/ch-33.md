## Description
Replace the shipped mozilla llamafile 0.10.1 composite (qwen3-embedding-0.6b-16k.llamafile, release asset v1.4.0) with an opencoti-llamafile c14 r19 build: bare engine (f7eea3ca) + ggml-vulkan .so/.dll (r19) + the same qwen3-embedding-0.6b Q8_0 GGUF. The embedded .args name no backend (no --gpu / -ngl / device): claude-hooks (embedding_manager mode + device) picks CPU or Vulkan and which device, so the engine never grabs the 3090 on its own and the user can change it. Goal: embed on solidpc's Radeon Renoir iGPU. Note: r19 Vulkan decodes 1-4% slower than r18 on RADV Renoir (bug-4393).
