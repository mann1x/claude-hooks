## Description
Found in the ch-24 confirmation council (csl-2026-10-25-1312-4ea5, ollama cloud, researcher pinned num_ctx 32768, aee0ecd; archived at benchmarks/consultants/results/2026-10-25/cloud-32k-grounding/). With the grounding capped (head 18,368 -> 7,288 tokens), folds land at 15–20k, but the room trigger fires at ~22k (0.9 x window minus the declared output room), so a lane has ~5k of headroom while one read_file / grep result is 2–5k. Result: a fold every 2–3 research calls, 115 compaction calls (full flow ~5 calls per fold) against 67 research calls; prompt tokens 2.35M. Levers to measure, not guess: a smaller kept tail under small windows (plan_cut recent-3 rule), the full flow's digest target (compaction_target_tokens = 0.25 x (max input - overhead)), the declared output room on a small window (model_max_output_of / 0.25 x window), or `reduced`/`basic` flow below some window. Any change must keep the fork's sizing rules ([[feedback_inherit_cerebriline_output_window]]) unless a measured arm shows otherwise.
