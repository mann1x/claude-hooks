# `/consultants` benchmark sweeps

This directory contains per-label benchmark runs of the canonical
queries documented in [`../consultants-benchmarks.md`](../consultants-benchmarks.md).

Each subdirectory is one label — typically a model tag plus a date
suffix when the same model is re-run after engine changes. Inside
each label, you'll find:

| File | What |
|---|---|
| `results.md` | Wall + status table; auto-generated by the runner |
| `<query>.summary.md` | The synthesizer's answer (verbatim) |
| `<query>.transcript.md` | Full role transcript |
| `<query>.waterfall.txt` | Per-role wall-time waterfall |
| `<query>.trace.jsonl` | Raw JSONL trace events |
| `<query>.metadata.json` | Token totals + retry counts |
| `<query>.status` | Wall, sid, status (machine-readable) |

## How to add a sweep

```bash
scripts/consultants_benchmark.sh <label> --model <ollama-tag>
```

Examples:

```bash
# Pin every role to a specific model
scripts/consultants_benchmark.sh kimi-k2.6-cloud-2026-05-07  # default config

scripts/consultants_benchmark.sh deepseek-v4-pro-2026-05-XX --model deepseek-v4-pro:cloud

scripts/consultants_benchmark.sh qwen3.5-cloud-2026-05-XX  --model qwen3.5:cloud
```

The label is yours to pick — convention is `<model-slug>-<date>`. If
you're A/B-testing engine config rather than models, use a
config-name suffix:

```bash
scripts/consultants_benchmark.sh kimi-k2.6-cloud-no-fanout-2026-05-07  # FANOUT_MAX_LANES=1
```

## Cross-label comparison

Once two or more labels exist, drop a comparison table at the bottom
of this file with wall-time deltas + answer-quality verdicts (manually
graded). Keep the per-label `results.md` files as raw data.

### Role-suitability matrix

Per [`EVALUATION.md`](EVALUATION.md) §3.5. Each cell is the
per-role grade aggregated across all three queries, plus the
median wall the role spent on this label (sum across query
invocations / parallel lanes). Use this to compose mixes:

> For each role, pick the cheapest model with grade ≥ A. If no
> model gets A on a role, pick the highest-grading available;
> ties broken by lower median wall.
